# Plateau U9 — Envoi des fiches

Appli téléphone de l'organisateur d'un plateau de football U9 : choix des clubs, planning des rotations et envoi de la fiche A6 de chaque équipe à son éducateur (WhatsApp, SMS).

En ligne : https://guyle72.github.io/plateau-u9/

Sur le téléphone : ouvrir le lien dans Chrome (Android) ou Safari (iPhone), puis « Ajouter à l'écran d'accueil ».

Le plateau en cours est enregistré uniquement sur le téléphone.
